## Sobre el proyecto {#about}

Este es el proyecto de laboratorio para el curso de EPCSD/ISCSD/SA de la UOC. Se compone de 5 elementos (cada uno es su propio submodulo en repositorios separados):

* El archivo de [docker-compose](https://github.com/UOC-SPRING-2026/spring-2026/blob/main/docker-compose.yml).
* El microservicio de [ProductCatalog](https://github.com/UOC-SPRING-2026/spring-2026-productcatalog).
* El microservicio de [User](https://github.com/UOC-SPRING-2026/spring-2026-user).
* El microservicio de [Notification](https://github.com/UOC-SPRING-2026/spring-2026-notification).
* El microservicio de [Course](https://github.com/UOC-SPRING-2026/spring-2026-course).
* El microservicio de [MicroCredential](https://github.com/UOC-SPRING-2026/spring-2026-microcredential).
